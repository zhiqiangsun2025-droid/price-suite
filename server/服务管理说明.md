## 快速管理命令

### 查看服务状态
```bash
ps aux | grep "python.*app.py" | grep -v grep
netstat -tulnp | grep :5000
```

### 手动重启服务
```bash
# 1. 找到进程ID
ps aux | grep "python.*app.py" | grep -v grep

# 2. 停止进程（替换PID为实际进程ID）
kill <PID>

# 3. 启动服务
cd "/www/wwwroot/ price-suite/server"
nohup python3 app.py > app_startup.log 2>&1 &
```

### 查看日志
```bash
# 查看应用日志
tail -f "/www/wwwroot/ price-suite/server/app.log"

# 查看启动日志
cat "/www/wwwroot/ price-suite/server/app_startup.log"
```

## Systemd 服务配置（可选）

已为您创建了systemd服务配置，可以实现开机自动启动。

### 使用Systemd管理（推荐）

**注意**: 使用systemd前需要先停止手动启动的进程！

#### 1. 停止当前手动进程
```bash
# 查找进程ID
ps aux | grep "python.*app.py" | grep -v grep

# 停止进程（替换35491为实际PID）
kill 35491
```

#### 2. 启用并启动systemd服务
```bash
# 启用开机自动启动
systemctl enable price-suite.service

# 启动服务
systemctl start price-suite.service

# 查看状态
systemctl status price-suite.service
```

#### 3. Systemd常用命令
```bash
# 启动服务
systemctl start price-suite

# 停止服务
systemctl stop price-suite

# 重启服务
systemctl restart price-suite

# 查看状态
systemctl status price-suite

# 查看日志
journalctl -u price-suite -f

# 禁用开机自动启动
systemctl disable price-suite
```

## 开机自动启动配置

### 方案1：使用 Systemd（推荐）
按照上面的Systemd配置步骤操作即可。

### 方案2：使用 rc.local
如果不想使用systemd，可以在 `/etc/rc.local` 添加：

```bash
cd /www/wwwroot/ price-suite/server && nohup python3 app.py > app_startup.log 2>&1 &
```

### 方案3：使用 crontab
```bash
# 编辑crontab
crontab -e

# 添加开机启动
@reboot cd /www/wwwroot/ price-suite/server && nohup python3 app.py > app_startup.log 2>&1 &
```

## 故障排查

### 问题1: 网站502错误
**原因**: Flask应用未启动

**解决**:
```bash
# 检查进程
ps aux | grep python.*app.py

# 如果没有进程，手动启动
cd "/www/wwwroot/ price-suite/server"
nohup python3 app.py > app_startup.log 2>&1 &
```

### 问题2: 重启后服务未启动
**原因**: 未配置开机自动启动

**解决**: 
- 按照上面的"开机自动启动配置"操作

### 问题3: 端口被占用
**解决**:
```bash
# 查找占用5000端口的进程
lsof -i :5000

# 停止该进程
kill <PID>
```

### 问题4: 权限问题
**解决**:
```bash
# 确保文件有执行权限
chmod +x "/www/wwwroot/ price-suite/server/app.py"
chmod +x "/www/wwwroot/ price-suite/server/start.sh"
```
