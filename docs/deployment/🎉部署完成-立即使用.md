## 🔧 管理命令

### 查看服务状态
```bash
# Flask服务
lsof -i :5000

# Cloudflare Tunnel
systemctl status cloudflared

# 查看日志
tail -f "/www/wwwroot/ price-suite/server/app.log"
```

### 重启服务
```bash
# 重启Flask
ps aux | grep "python3 app.py" | grep -v grep | awk '{print $2}' | xargs kill
cd "/www/wwwroot/ price-suite/server" && python3 app.py &

# 重启Tunnel
systemctl restart cloudflared
```

## ❓ 常见问题

### Q1: 域名打不开？
A: DNS可能还在生效中，请等待1-5分钟。可以先使用 `http://localhost:5000/admin/login` 访问。

### Q2: 如何修改密码？
A: 登录后台后，在设置中修改。

### Q3: 如何添加新客户端？
A: 后台 → 客户端管理 → 添加新客户端

### Q4: 如何查看系统日志？
A: 后台 → 请求日志 / 事件日志

### Q5: 系统会自动启动吗？
A: 是的，服务器重启后会自动启动Cloudflare Tunnel。Flask需要手动配置systemd服务（可选）。
