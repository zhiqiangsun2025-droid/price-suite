## 🔒 配置SSL证书（推荐）

### 方案1：使用宝塔面板（最简单）

1. 登录宝塔面板
2. 网站 → 找到 `price.deepopenai.store`
3. SSL → Let's Encrypt
4. 勾选域名后点击"申请"
5. 开启"强制HTTPS"

### 方案2：使用Cloudflare SSL（已经开启代理的话）

如果您在Cloudflare开启了代理（橙色云朵），Cloudflare会自动提供SSL证书，无需在服务器端配置。
